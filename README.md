# 3D Viewer Android app

This repository contains an Android WebView wrapper for the supplied Arena Web Dev HTML application. The original HTML must be placed at `app/src/main/assets/index.html` before building.

## Cloud build
Open the **Actions** tab, select **Build 3D Viewer APK**, choose **Run workflow**, and download the `3D-Viewer-debug-APK` artifact after the run completes.

This produces a debug APK for personal installation, not a Play Store release.
